# Git

工具 ID：`git`。原项目：[git/git](https://github.com/git/git)，[官方 macOS 安装](https://git-scm.com/downloads/mac)。

先 `command -v git`、`git --version`。Apple CLT 已提供且满足需求时保留；缺失可由 [CLT](apple-clt.md) 提供，选择 Homebrew Git 时执行 `brew install git` 并确认 PATH。

姓名、邮箱、签名和 SSH key 不从本仓库作者复制。自动模式保留既有身份；没有身份时只装软件，将身份配置列为待用户提供，不编造邮箱，不擅自改全局 signing。

升级沿实际渠道。验证版本和临时仓库基本操作，不创建远程仓库、不 push、不测试提交到用户真实项目。

核验：2026-08-31。共通选择与冲突规则见 [执行策略](../guides/selection-and-conflicts.md)。
