# 盘点、变更与回滚

选择与冲突由 [共享规则](selection-and-conflicts.md) 定义，本页负责现场执行方法。auto/ask 的区别不影响备份、来源核验与验收要求。

## 只读盘点

先确认 `uname -s` 为 Darwin，连接的是用户要配置的 Mac。系统信息用 `sw_vers`、`uname -m`、`sysctl -in sysctl.proc_translated`（无该键不视为故障）。不记录序列号。

1. 识别实际 shell。zsh 检查 ZDOTDIR、zshenv/zprofile/zshrc 的真实路径、符号链接、框架、PATH 和相关 source；不打印含秘密的整个配置文件。
2. 先检查基础环境，按用户范围检查对应命令。`command -v`、zsh 的 `whence -a` 配合链接/包记录识别渠道。无 rg 时用系统 grep，不为了盘点先装包。nvm 是函数，不只检查可执行文件。
3. Brew 存在才读 prefix、formula/cask 清单；同时发现 arm64/Intel 安装时不自动换架构。Node/Python 结合管理器、当前解释器和用户指定项目约束检查，不遍历全部虚拟环境或全局包秘密。
4. GUI 核对 App 路径、bundle ID、版本和分发来源；App 同名不等于同产品。仅检查所选软件的配置入口，避免广扫用户目录。
5. 检查相关同名函数、快捷键、launchd label 和已有配置块。旧报告仅作为线索，先验证本机现状与当前用户选择。
6. 非敏感盘点和选择快照写 `.local/setup-<日期时间>.md`，不提交 Git。

## 计划和执行顺序

把所选目标展开为明确列表，记录原状态、保留/新增/修复/跳过、官方依据、依赖、预计改动、备份回滚及账号步骤。按依赖图排序，GUI/无依赖工具可独立继续；某项受限不阻塞全局。

执行前核验当前 package engines、Brew 依赖图、安装器写入范围和平台支持，过滤黑名单。下载安装器到 `.local/downloads/`，检查来源、内容和可用的签名/校验，再执行这份文件；不能审阅一份又下载另一份执行，不编造验证结果。文档中的尖括号路径/版本占位符必须替换后才能执行。

用户已选择安装范围或“一键全选自动处理”时，展示计划后连续执行。ask 仅对实际未决冲突集中询问；auto 依据单工具页和共享规则自行解决，无法在范围内安全完成的项记录并跳过。安装请求不是全局升级/迁移的授权。

## 最小修改

每个将修改的文件先备份，保留模式/内容，记录链接实际指向、摘要和位置。备份默认 `.local/backups/<本次ID>/`；修改前检查并发变更，发生漂移就重新合并，不能覆盖用户新写内容。

优先独立片段、唯一管理块；识别历史标记与等价 source 后再写。无差异就不修改；相同初始化不加载两次。加载顺序一般为 Homebrew → 单一生效的版本管理器 → 所选 shell 集成，并检查后续插件是否再次改 PATH。

```zsh
# >>> oh-my-new-mac:rm-async >>>
[[ -r "$HOME/.config/rm-async/functions.zsh" ]] && source "$HOME/.config/rm-async/functions.zsh"
# <<< oh-my-new-mac:rm-async <<<
```

这是 rm-async 的块示例，不是全机配置内容；使用真实 ZDOTDIR 入口。不通过 `cat > ~/.zshrc` 覆盖整个文件。安装器若自行改 profile，执行前备份、之后审阅 diff；上游明确支持关闭自动 profile 修改时优先使用该方式。

自定义函数/按键不能无损合并时，ask 展示差异；auto 保留原内容、跳过这一集成，并继续可独立完成的安装。不要为了凑“全选成功”强行删除旧内容。

## 记录、恢复和回滚

- 每项记录实际命令、渠道、版本、退出码、文件差异、验证层级和下一步。不用已有二进制掩盖刚刚失败的安装。
- shell 回滚只回退本次差异，不能用旧备份覆盖后来新增内容。工具卸载按真实渠道并检查依赖；不跑批量 cleanup。
- 活跃 rm_async 任务不会因移除加载块而停止；保留 worker/状态，不自动重试未知删除。
- 定时任务仅在用户明确选择时生成；恢复时先核验精确 label 是否已存在。撤销时仅停用本次任务，不清理所有 LaunchAgents。
- 机器不可访问、登录未完成、受企业策略限制时，继续独立项，交接明确尚未满足的目标。
