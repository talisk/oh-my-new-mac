# 盘点、变更与回滚

## 只读盘点

先确认 `uname -s` 为 Darwin，且连接的就是目标 Mac。系统信息用 `sw_vers`、`uname -m`、`sysctl -in sysctl.proc_translated`（不支持该键不视为故障）。不要记录序列号等无关信息。

1. 识别用户实际使用的 shell。zsh 检查 `ZDOTDIR`、`.zshenv`、`.zprofile`、`.zshrc` 是否存在及是否为符号链接。只查看 PATH、source、版本管理器、alias/function 和本仓库标记附近，避免输出整个含秘密的配置。
2. `command -v` 和 zsh 的 `whence -a` 检查每个**所选**命令；`ls -l` 识别链接。不能假设每台 macOS 都有 `readlink -f`。需要规范化路径时可用 zsh 的 `:A` 修饰符；这是用于诊断，不用它重写删除目标。
3. Homebrew 存在才读 `brew --prefix`、`brew list --formula --versions`、`brew list --cask --versions`。同时发现 `/opt/homebrew` 与 `/usr/local` 安装时，不自动切架构或 link 覆盖。
4. Node 管理器按实际存在的 nvm/fnm/mise/系统渠道识别，检查当前 `node --version`、`npm --version`、`npm prefix -g`。Python 只检查版本、解释器来源和已有工具管理器。不要升级所有全局包或遍历用户全部虚拟环境。
5. 检查相关 launchd label、PATH 片段和已有同名函数。没有 `rg` 时用系统 `grep`，不为了盘点先安装工具。
6. 保存不含秘密的结果到 `.local/setup-<日期时间>.md`。只对本次目标模块检测，不广泛扫描主目录。

## 每项的决策表

| 现状 | 默认处理 | 可建议的改进 |
|---|---|---|
| 缺失，来源明确 | 用户选择后安装 | 列出依赖与路径 |
| 已安装且可用 | 保留并验证 | 可建议更新，但不默默升级 |
| 重复渠道 | 记录当前生效来源；全部保留 | 给出选定单一渠道的迁移计划 |
| 旧版本满足项目 | 保留 | 单独列出兼容性或安全更新理由 |
| 同名函数/配置有自定义 | 展示差异，不覆盖 | 合并到用户指定位置或采用另一个名称 |
| 官方来源/架构/命令不明 | 待核验，跳过该项 | 索取原项目/官方文档，不用第三方同名项目替代 |
| 无网络/公司策略限制 | 继续可完成项 | 列出受影响项目；不换来历不明镜像 |

## 最小修改

备份每个将修改的文件，保留其模式和内容；记录真正的目标路径（链接指向）及内容摘要。`.local/backups/<本次ID>/` 只保存在本机。修改前再次确认它没有被用户并发编辑；发生变化则重新合并。

安装器可能自行改 shell，运行前备份相关入口；运行后审查 diff，不重复手工追加。能按照官方方法禁用自动改 profile 的安装器，优先让 agent 管理独立加载片段。

约定的加载块示例：

```zsh
# >>> oh-my-new-mac:rm-async >>>
[[ -r "$HOME/.config/rm-async/functions.zsh" ]] && source "$HOME/.config/rm-async/functions.zsh"
# <<< oh-my-new-mac:rm-async <<<
```

这只是示例。先识别旧 `rm-async` 标记、直接 source、同名函数和 `ZDOTDIR`。相同内容不再追加；不同内容先给差异。不要通过 `cat > ~/.zshrc` 替换整个文件。

运行官方安装器时先下载到 `.local/downloads/`，检查 URL、文件内容、平台要求、写入范围与可用校验信息，再运行这份已检查的文件；不在审阅后另下一个未经审阅的脚本。不要编造签名或哈希验证结果。

## 恢复和回滚

- 每完成一项写入报告：组件/原来源/现来源/修改文件/备份/命令退出码/验证/下一步。中断后根据报告与实际状态接着做。
- 回滚 shell 时只回退本次差异，不用整份旧备份覆盖用户后来新增的内容。
- 删除加载块不会中止正在运行的 `rm_async`。有活跃任务时保留 worker 和状态目录，不自动重试或继续未知删除任务。
- 撤销新增工具应使用其实际安装渠道，并先确认它没有成为其他软件的依赖；不运行批量清理。
- 撤销定时升级先 `bootout` 对应本机 label，再移除本次创建的 plist；不要停掉其他任务。
- 包管理器升级未必能原地降级；迁移前检查上游旧版本是否可得，不承诺不存在的“完整回滚”。
