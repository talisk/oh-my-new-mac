# GUI 应用

这是该分类的可选条目清单。每个文件负责一个工具/App；全选本分类会展开所有条目，但仍遵守黑名单与 [冲突策略](../guides/selection-and-conflicts.md)。

| 工具 ID | 工具 / 安装说明 | 可识别别名 | 范围与注意事项 |
|---|---|---|---|
| `otty` | [Otty Terminal](otty.md) | Otty | otty.sh / Appmakes 发行版 |
| `warp` | [Warp Terminal](warp.md) | Warp | 官方桌面终端 |
| `zed` | [Zed](zed.md) | Zed | 编辑器与自带 CLI |
| `chrome` | [Google Chrome](chrome.md) | google-chrome、Chrome | 保留 profile 与默认浏览器选择 |
| `codex-desktop` | [Codex Desktop](codex-desktop.md) | codex-app | 独立产品；当前分发状态需再核验 |
| `cursor-desktop` | [Cursor Desktop](cursor-desktop.md) | Cursor Desktop | 编辑器，不自动加装 Cursor CLI |
| `caffeine` | [Caffeine](caffeine.md) | Caffeine | 辨别 IntelliScape / Domzilla 发行方 |
| `amphetamine` | [Amphetamine](amphetamine.md) | Amphetamine | Mac App Store；不装同名伪 cask |

全选允许多个终端/编辑器共存，不修改默认 App。配置防休眠工具不代表开启持续唤醒；账号、App Store、收费与系统审批仍受宿主限制。来源变化或不可自动完成的项单独记录，不阻塞其他项。
