# 历史附件，不是可执行配置方案

本目录两份 Markdown 从用户提供的同名文件逐字复制，保留上下文与原始内容。它们描述的是某台已有 Mac 在过去某时刻的状态，不保证适用于其他机器或当前版本。

使用维护版 [AI CLI 与升级](../ai-cli-upgrade.md) 和 [终端工具指南](../terminal-cheatsheet.md)；不要直接执行这里的安装/升级/发布/删除示例。

需要特别纠正：

- 旧 Codex npm 与 Brew 双装状态不是通用要求；只维护用户选定的渠道。
- 旧 Claude `claude-code@latest` cask 名称不能当作所有机器的默认值。盘点原 token 后再决定是否迁移。
- `StartCalendarInterval` 在睡眠错过时间后可在唤醒时运行，并非原文所说永远不补跑；关机是另一种情况。
- yazi 的按键、spotatui 的平台能力、Surge 的 DNS/HTTPS 服务和 PicGo 的命令均可能随版本变化。
- `rg -n` 不能省略成“总是默认带行号”；输出到管道时默认行为不同。`-S` 是模式含大写时区分大小写，否则不区分。
- 发布站点、下线站点、上传图片、永久删除和显示令牌都不是安装验证动作。
